# Python Problem Solving

A collection of Python programs and problem-solving exercises focused on developing programming logic and applying Python concepts.

## Programs

### Conditional Statements
- Even or Odd
- Positive, Negative, or Zero
- Leap Year
- Largest of Three Numbers

## Concepts Covered
- Conditional statements (`if`, `elif`, `else`)
- Comparison operators
- Modulo operator (`%`)
- Logical operators
- Conditional logic

More programs and exercises will be added as the repository grows.
